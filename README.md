# Multimodal RAG Agent

A Multimodal Retrieval-Augmented Generation (RAG) system built using:

- Streamlit
- ChromaDB
- Groq LLM
- OCR
- CLIP
- LangChain

## Features

- PDF Question Answering
- Image OCR
- Semantic Search
- Multimodal Retrieval
- AI-Powered Answers

## Tech Stack

- Python
- Streamlit
- ChromaDB
- Groq API
- Sentence Transformers
- Tesseract OCR

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
